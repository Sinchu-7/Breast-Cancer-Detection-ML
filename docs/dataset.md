\# Dataset Documentation

This repository contains two separate experiments: the image-classification
pipeline uses BreakHis, while the tabular baseline in `src/train_model.py`
uses the Wisconsin Diagnostic Breast Cancer dataset described below. The
Wisconsin dataset is not used by the BreakHis image model or Streamlit app.



\## Dataset Name

Wisconsin Diagnostic Breast Cancer (WDBC)



\## Source

UCI Machine Learning Repository



https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic



\## Dataset Information

\- Total Samples: 569

\- Total Features: 30

\- Classification: Binary Classification

\- Target Classes: Benign and Malignant



\## Objective

To use diagnostic measurements to build a

machine learning classification model.



\## Features

The dataset contains measurements such as:

\- Radius

\- Texture

\- Perimeter

\- Area

\- Smoothness

\- Compactness

\- Concavity

\- Symmetry



\## Target

\- M: Malignant

\- B: Benign



\## Purpose

This dataset will be used for educational

machine learning experiments.
