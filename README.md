# Breast Cancer Detection Using Machine Learning

## About the Project

This project explores Machine Learning techniques
to classify breast cancer diagnostic samples as
Benign or Malignant.

## Objective

To understand how machine learning algorithms
analyze diagnostic measurements and perform
binary classification.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

Wisconsin Diagnostic Breast Cancer Dataset (WDBC).

## Project Status

Currently under development.

## Disclaimer

This project is for educational and research
purposes only. It is not a medical diagnostic tool.
